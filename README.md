# Smart-tourist

- це система для пошуку та бронювання подорожей по Україні. Цей проект буде створений для зручного бронювання, пошуку та планування екскурсій і вільному вибору міст.

💡Актуальність теми:
 У сучасних реаліях внутрішній туризм в Україні стрімко розвивається, проте багато цікавих локацій та екскурсій не мають єдиної цифрової платформи для швидкого пошуку і бронювання. Саме наша платформа вирішує цю проблему, забезпечуючи зручний вибір міст, перегляд детальної інформації про тури, миттєве бронювання та систему реальних відгуків.

👌Мета та задачі:
 Забезпечити зручний пошук, планування та бронювання подорожей і екскурсій містами України.

 Основні задачі:
- Розробити структуру системи та визначити головні сутності (Міста, Екскурсії, Бронювання, Відгуки).
- Реалізувати функціонал пошуку екскурсій за заданим містом.
- Забезпечити перегляд детальної інформації про кожну екскурсію.
- Додати можливість бронювання екскурсій та залишення відгуків.
- Провести тестування функціональності та перевірити роботу системи через конвеєр.

🧠Бізнес-логіка
 Система «Smart-tourist» об’єднує користувачів (туристів) та адміністраторів/гідів:
 1. Користувачі (Туристи): обирають місто, шукають екскурсії, дивляться детальний опис, бронюють місця та залишають відгуки  про поїздки.
 2. Адміністратори / Гіди: додають нові екскурсії, керують розкладом, модерають відгуки та перевіряють статус бронювань.

🦾Функціональні вимоги:
- Пошук екскурсії по заданому місту.
- Перегляд детальної інформації про екскурсію (опис, програма, ціна, доступні місця).
- Бронювання екскурсії (збереження даних туриста та фіксація місць).
- Створення та перегляд відгуків (оцінки та коментарі користувачів).

🧠 Нефункціональні вимоги
- Сумісність із сучасними браузерами: Google Chrome, Mozilla Firefox, Microsoft Edge (не старіші за 2020 рік).
- Швидкість завантаження сторінок: до 2–3 секунд.
- Адаптивний дизайн для мобільних пристроїв і ПК.
- Безпечне збереження користувацьких даних.
