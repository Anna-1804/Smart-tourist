# Smart-tourist

- це система для пошуку та бронювання подорожей по Україні. Цей проект буде створений для зручного бронювання, пошуку та планування екскурсій і вільному вибору міст.

Система надаватиме наступні можливості:

- пошук екскурсії по заданому місту;
- перегляд детальноъ інформації про екскурсію;
- бронювання екскурсії;
- створення та перегляд відгуків.

Інструкція, як запустити проєкт локально
Клонування репозиторію через VS Code:

1. У новому вікні VS Code обрати "Clone Git Repository"
2. Ввести https посилання "https://github.com/Anna-1804/Smart-tourist.git"
3. Обрати локальну папку на пристрої, куди і буде клоновано даний репозиторій.
